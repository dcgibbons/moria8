moria8 / 6502 & Z80 roguelike, eight ports, five cartridges

A from-scratch assembly port of Moria targeting the Commodore 64, 128, Plus/4, Apple IIe, Commander X16, Atari 8-bit (800XL/65XE/130XE), Acorn BBC Master 128, and CP/M 2.2 (Z80) — plus five ROM cartridges (C64, C128, Plus/4, CX16, Atari 8-bit) — separating platform-agnostic 6502 (core/6502/) and Z80 (core/z80/) game cores from hardware-specific HALs. This page and its companion architecture-map.json mirror the current repository tree.

repository layout

Gameplay logic lives in core/6502/ (shared across all seven 6502/65C02 ports) and core/z80/ (parallel Z80 engine). Everything under platforms/ supplies display, input, memory, and loader services behind target-specific HAL implementations — no hardware register touches core/.

five ROM cartridge memory models

moria8-c64.crtType 32 512 KB ROML ($8000–$9FFF via $DE00, 17 ROML + 1 Ultimax boot ROMH; 132,845 B ROML, 23 assets at $8100). Copies Default ($B638, 44,599 B) + 64.bank at boot; streams overlays/catalogs/ITEM.CAT via ROML; saves on IEC 8–11.
moria8-plus4.crtc264 magic cart Type 1 (16×16 KB = 256 KB, 141,540 B used, 23 assets at $8100, C1LO $FDD2 + $FDFE). Enters $100E; streams 13 overlays (ovl.storage 4,092 B), MONSTER.CAT/EXT, ITEM.CAT, legalui from $8000–$BFFF ROM; omits disk sector LRU; saves on IEC 8–11.
moria8-c128.crtMagic Desk 128 Ext Func ROM (Type 4, 16×16 KB = 256 KB, 141,718 B used, 30/32 assets at $8100). Boot copies Bank 0/1 payloads via $1FBF cart_reader + $0FB0 common bounce; hal_item_cat_cart_read_byte reads ITEM.CAT from ROM instead of VDC RAM; saves on IEC 8–11.
moria8-cx16.crt128 KB X16 ROM (Banks 32–39 at $C000–$FFFF via ZP $01, 122,656 B used, 23 assets at $C100). Zero-bounce $0400 boot copier loads low RAM + HiRAM Banks 3–23 straight from ROM without touching $A000–$BFFF; legal views stream from ROM; saves use KERNAL/SD.
moria8-atari8.carAtariMax 128 KB Type 41 (16×8 KB at $A000–$BFFF via $D500, 127,798 B used, 21 assets at $A100). Writes $D510 (RD5=0) between accesses so Main RAM MORIA8.RES ($0C00–$BDCB, 45,515 B) stays visible; compiles out 130XE cache; streams overlays + uncompressed 57 B/rec catalogs; saves via SIOV.

core modules

05

HAL contract

Contract-only directory: platform-specific register writes, banking mechanics, KERNAL/OS wrappers, and drive behavior belong under the owning platform — never here. platforms/commodore/hal/hal_contract.s aggregates ten interface modules; platforms/apple2/hal/, platforms/cx16/hal/, platforms/atari8/hal/, platforms/bbcmaster/hal/, and platforms/z80/cpm/hal/ implement the equivalent surface against their respective native OS, display, terminal, and banking hardware.
hal_lifecycle.sBoot / init / shutdown sequencing
hal_memory.sBank switching / memory visibility
hal_irq.sInterrupt hook contract
hal_layout.sScreen geometry (40 vs. 80 col)
hal_screen.sCharacter-mapped display
hal_input.sKeyboard / joystick input
hal_sound.sSID / POKEY / SN76489 / VERA / speaker sound
hal_storage.sDisk / save / cartridge I/O, phase-banded status codes
hal_overlay.sOverlay load / cache contract
hal_entropy.sRNG seed / entropy source

C64 import cascade

Deduplicated top-level #import order in platforms/commodore/c64/main.s — platform HAL/services first, then resident core modules, then banked overlays and cold legal screens. The other six ports follow the same shape against their own platform files.
