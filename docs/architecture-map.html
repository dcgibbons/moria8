moria8 / 6502 roguelike, four ports, one core

A from-scratch assembly port of Moria targeting the Commodore 64, 128, Plus/4, and Apple IIe — all four sharing a single platform-agnostic game core behind a strict hardware abstraction layer. This page and its companion architecture-map.json are derived from the current main branch tree.

05

HAL contract

Contract-only directory: platform-specific register writes, banking mechanics, KERNAL wrappers, and drive behavior belong under the owning platform — never here. platforms/commodore/hal/hal_contract.s aggregates ten interface modules; platforms/apple2/hal/ implements the same surface against ProDOS MLI and IIe aux-bank memory instead of KERNAL/IEC.
hal_lifecycle.sBoot / init / shutdown sequencing
hal_memory.sBank switching / memory visibility
hal_irq.sInterrupt hook contract
hal_layout.sScreen geometry (40 vs. 80 col)
hal_screen.sCharacter-mapped display
hal_input.sKeyboard / joystick input
hal_sound.sSID / TED sound
hal_storage.sDisk / save I/O, phase-banded status codes
hal_overlay.sOverlay load / cache contract
hal_entropy.sRNG seed / entropy source

C64 import cascade

#import order in platforms/commodore/c64/main.s — platform HAL/services first, then core in dependency order, then disk/save glue, then the game loop. The other three ports follow the same shape against their own platform files.
